# Monthly literature screening

This repo is the group's literature screening profile. When asked to run the monthly screening:

- Follow `selection-rules.md`: journals in section 2, topics in section 3, rules, scoring and tags in section 4, and the task prompt and output format in section 5.
- Save the result as `reviews/YYYY-MM.md` for the month screened.
- Never include the names of people who posted or recommended papers.

See `README.md` for the full how-to.
